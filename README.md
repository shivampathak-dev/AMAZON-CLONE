# 🛒 Amazon Clone

A front-end **Amazon-inspired e-commerce website clone** built using **HTML and CSS** as part of my Full Stack Development learning journey.

This project was created to apply my HTML and CSS knowledge to a practical real-world website and strengthen my understanding of frontend development.

## 🚀 What I Practiced

* HTML5 semantic structure
* CSS3 styling and layouts
* Flexbox
* CSS Grid
* Positioning
* Responsive web design
* Navigation bars and sections
* Product cards and layouts
* Buttons and visual styling
* Multi-section webpage structure
* Using external libraries and CDNs

## 🛠️ Technologies & Tools Used

* **HTML5** — Website structure
* **CSS3** — Styling and layouts
* **Font Awesome** — Icons and visual elements
* **cdnjs** — CDN used to load Font Awesome resources

## 🎯 Purpose

The goal of this project was to move beyond tutorials and **build a practical project using the concepts I had learned in HTML and CSS**.

This is one of the early projects in my Full Stack Development journey and helped me gain hands-on experience with creating structured, visually appealing frontend interfaces.
